# Notes @mentions + real-time notifications — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Quill rich-text editor with `@mentions` to the notes form, and notify mentioned team members through a persisted notification center plus a live Reverb toast.

**Architecture:** Quill (+ quill-mention) authors HTML; the server sanitizes it with HTMLPurifier, parses `span[data-id]` tokens to resolve mentioned users, syncs a `mentions` pivot, and fires a Laravel notification that both persists (database) and broadcasts (Reverb) to the mentioned user's private channel. The Vue layout shows a notification bell fed by Inertia shared props and updated live over Laravel Echo.

**Tech Stack:** Laravel 13, Inertia v3 + Vue 3, Pest 4, Quill 2 + quill-mention, mews/purifier, Laravel Reverb + Echo + pusher-js, Tailwind v4.

```vue
<!--
  RichTextEditor
  --------------
  Quill 2 editor with @mention autocomplete (quill-mention). v-model-compatible:
  emits the editor's HTML on every change. Mentions insert
  <span class="mention" data-id="{userId}">@Name</span> tokens, which the server
  parses to resolve who was mentioned.
-->
<script setup>
import { onBeforeUnmount, onMounted, ref, watch } from 'vue'
import Quill from 'quill'
import { Mention, MentionBlot } from 'quill-mention'
import 'quill/dist/quill.snow.css'

Quill.register({ 'blots/mention': MentionBlot, 'modules/mention': Mention })

const props = defineProps({
  modelValue: { type: String, default: '' },
  placeholder: { type: String, default: 'Write a note…' },
})

const emit = defineEmits(['update:modelValue'])

const editor_el = ref(null)
let quill = null

onMounted(() => {
  quill = new Quill(editor_el.value, {
    theme: 'snow',
    placeholder: props.placeholder,
    modules: {
      toolbar: [['bold', 'italic', 'underline', 'strike'], [{ list: 'ordered' }, { list: 'bullet' }], ['link']],
      mention: {
        allowedChars: /^[A-Za-z0-9\s._-]*$/,
        mentionDenotationChars: ['@'],
        dataAttributes: ['id', 'value'],
        source: async (search_term, render_list) => {
          const params = new URLSearchParams({ q: search_term ?? '' })
          const res = await fetch(`/users/mentionable?${params}`, { headers: { Accept: 'application/json' } })
          const users = await res.json()
          render_list(users.map((user) => ({ id: user.id, value: user.full_name })), search_term)
        },
      },
    },
  })

  if (props.modelValue) {
    quill.clipboard.dangerouslyPasteHTML(props.modelValue)
  }

  quill.on('text-change', () => {
    const html = quill.getLength() > 1 ? quill.root.innerHTML : ''
    emit('update:modelValue', html)
  })
})

// Allow external resets (e.g. form.reset()) to clear the editor.
watch(
    () => props.modelValue,
    (value) => {
      if (quill && value === '' && quill.getLength() > 1) {
        quill.setText('')
      }
    },
)

onBeforeUnmount(() => {
  quill = null
})
</script>

<template>
  <div class="rounded-md border border-input bg-transparent">
    <div ref="editor_el" />
  </div>
</template>
```

```php
<?php

namespace App\Services;

use App\Models\Note;
use App\Models\User;
use Illuminate\Support\Collection;

/**
 * Resolves the users mentioned in a note's sanitized HTML and keeps the
 * note's `mentions` pivot in sync. The note content is the single source of
 * truth — IDs are parsed from `span[data-id]` tokens, never trusted from the
 * client directly.
 */
class NoteMentionService
{
    /**
     * Sync the note's mentioned users from its HTML content.
     *
     * @return Collection<int, User> the users newly mentioned by this sync
     */
    public function syncFromContent(Note $note, string $html, ?int $excludeUserId = null): Collection
    {
        $ids = $this->extractUserIds($html)
            ->reject(fn (int $id): bool => $id === $excludeUserId);

        $valid_ids = User::query()->whereKey($ids)->pluck('id');

        $existing_ids = $note->mentionedUsers()->pluck('users.id');

        $note->mentionedUsers()->sync($valid_ids);

        return User::query()
            ->whereKey($valid_ids->diff($existing_ids))
            ->get();
    }

    /**
     * Parse distinct user IDs from `data-id` attributes in the content.
     *
     * @return Collection<int, int>
     */
    protected function extractUserIds(string $html): Collection
    {
        preg_match_all('/data-id="(\d+)"/', $html, $matches);

        return collect($matches[1])
            ->map(fn (string $id): int => (int) $id)
            ->unique()
            ->values();
    }
}
```

```php
namespace App\Notifications;

use Illuminate\Notifications\Notification;

class UserMentionedInNote extends Notification

    use Queueable;

    public function __construct(
        public Note $note,
        public User $mentioner,
    ) {}

    /**
     * @return array<int, string>
     */

     * @return array<string, mixed>

        return [
            'note_id' => $this->note->id,
            'mentioner_name' => $this->mentioner->full_name,
            'parent_label' => $this->parentLabel($notable),
            'url' => $this->parentUrl($notable),
            'snippet' => Str::limit(strip_tags($this->note->content), 100),

        return match (true) {
            $notable instanceof Customer => route('customers.show', $notable),
            $notable instanceof Company => route('companies.show', $notable),
```

# Contacts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add polymorphic Contacts (address + phones, typed) to Customers and Companies, with the primary contact shown inline on each Show page and all contacts managed through a full-CRUD modal.

**Architecture:** Mirror the existing **Notes** feature end-to-end. Backend: a corrected `Contact` model, a `WithContacts` trait on both parent models, a `ContactController` (store/update/destroy/setPrimary) with flat resource routes, and a `ContactRequest`. Frontend: a new `reka-ui`-based `Dialog` primitive plus a `Contacts/` component family (`ContactsSection` → inline `ContactCard` + `ContactsModal` → `ContactItem`/`ContactForm`).

**Tech Stack:** Laravel 13, PHP 8.4, Inertia v3, Vue 3, Tailwind v4, reka-ui v2, Pest v4, lucide-vue-next.

## Global Constraints

- Naming: `snake_case` variables, `camelCase` methods, `TitleCase` classes. PHP control structures always use curly braces; use constructor property promotion; explicit return types and param type hints.
- Seeders/factories must only reference existing users/companies/customers; never create a parent to satisfy a relationship.
- Run `vendor/bin/pint --dirty --format agent` after modifying PHP, before each commit.
- Run tests with `php artisan test --compact` filtered to the relevant file.
- Request field names for the parent follow the Notes convention: `model_type` (`'customer'`/`'company'`) and `model_id`. The morph columns on the table are `contactable_id` / `contactable_type`.
- `Contact::TYPES = ['Office', 'Billing', 'Shipping', 'Mailing', 'Other']`.
- Invariant: at most one primary contact per parent; when a parent has ≥1 contact, exactly one is primary.

namespace App\Models\Concerns;

use App\Models\Contact;
use Illuminate\Database\Eloquent\Relations\MorphMany;
use Illuminate\Database\Eloquent\Relations\MorphOne;

/**
 * Adds a polymorphic `contacts` relationship backed by the {@see Contact} model.
 */
trait WithContacts
{
    public function contacts(): MorphMany
    {
        return $this->morphMany(Contact::class, 'contactable')
            ->orderByDesc('is_primary')
            ->latest();
    }

    public function primaryContact(): MorphOne
    {
        return $this->morphOne(Contact::class, 'contactable')
            ->where('is_primary', true);
    }
}

- [ ] **Step 1: Create the controller**

Create `app/Http/Controllers/ContactController.php`:

```php
<?php

namespace App\Http\Controllers;

use App\Http\Requests\ContactRequest;
use App\Models\Company;
use App\Models\Contact;
use App\Models\Customer;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\RedirectResponse;
use Illuminate\Support\Facades\DB;

class ContactController extends Controller
{
    /**
     * Whitelist of models that may receive contacts, keyed by the
     * `model_type` value accepted from the client.
     *
     * @var array<string, class-string<Model>>
     */
    protected array $models = [
        'customer' => Customer::class,
        'company' => Company::class,
    ];

    /**
     * Fields copied straight from the request onto a contact.
     *
     * @var list<string>
     */
    protected array $fields = [
        'type',
        'street_address',
        'city',
        'state',
        'zip',
        'work_phone',
        'mobile_phone',
    ];

    /**
     * Store a contact against the given contactable model.
     */
    public function store(ContactRequest $request): RedirectResponse
    {
        $validated = $request->validated();

        $model = $this->resolveModel($validated['model_type'], $validated['model_id']);

        DB::transaction(function () use ($request, $model): void {
            $contact = $model->contacts()->create($request->safe()->only($this->fields));

            $should_be_primary = $request->boolean('is_primary')
                || $model->contacts()->count() === 1;

            if ($should_be_primary) {
                $this->makePrimary($contact);
            }
        });

        return back();
    }

    /**
     * Update an existing contact.
     */
    public function update(ContactRequest $request, Contact $contact): RedirectResponse
    {
        DB::transaction(function () use ($request, $contact): void {
            $contact->update($request->safe()->only($this->fields));

            if ($request->boolean('is_primary')) {
                $this->makePrimary($contact);
            }
        });

        return back();
    }

    /**
     * Remove a contact.
     */
    public function destroy(Contact $contact): RedirectResponse
    {
        $contact->delete();

        return back();
    }

    /**
     * Promote the given contact to be its parent's primary contact.
     */
    public function setPrimary(Contact $contact): RedirectResponse
    {
        DB::transaction(fn () => $this->makePrimary($contact));

        return back();
    }

    /**
     * Make the contact primary and demote its siblings.
     */
    protected function makePrimary(Contact $contact): void
    {
        $contact->contactable->contacts()
            ->whereKeyNot($contact->getKey())
            ->update(['is_primary' => false]);

        $contact->update(['is_primary' => true]);
    }

    /**
     * Resolve the target contactable model from the whitelist.
     */
    protected function resolveModel(string $type, int|string $id): Model
    {
        return $this->models[$type]::findOrFail($id);
    }
}
```

  editingId.value = null;

  editingId.value = contact.id;

    {},

            v-if="!showForm"
            variant="outline"
            size="sm"

        >
          <Plus class="size-4" />
          Add contact
        </Button>
      </div>

      <ContactForm
          v-if="showForm"
          :contactable_type="contactable_type"
          :contactable_id="contactable_id"
          :types="types"
          @saved="onSaved"
          @cancel="showForm = false"
      />

      <div
          v-if="contacts.length"
          class="space-y-3"
      >
        <template
            v-for="contact in contacts"
            :key="contact.id"
        >
          <ContactForm
              v-if="editingId === contact.id"
              :contactable_type="contactable_type"
              :contactable_id="contactable_id"
              :contact="contact"
              :types="types"
              @saved="onSaved"
              @cancel="editingId = null"
          />
          <ContactItem
              v-else
              :contact="contact"
              @edit="startEdit"
              @remove="removeContact"
              @set-primary="setPrimary"
          />
        </template>
      </div>
      <p
          v-else-if="!showForm"
          class="text-sm text-muted-foreground"
